# 探栏

中文名：**探栏** · 前缀 `probe` · 端口 **8100**

## 骨架（新骨）

**传感报文装载 → 标定/质控门槛入栏 → 站点汇总物化 → 坏点旁路 → 栏账互证**

| 对比 | 潮切 | 对拍 | **本仓** |
| --- | --- | --- | --- |
| 拓扑 | 事件时入窗→关窗 | 双轨对齐 | **质控门槛入栏→站点汇总** |
| 在途 | 入窗缓冲 | 悬账 | **入栏缓冲（过门槛未汇总）** |
| 产物 | 窗切片 | 对齐差+结论 | **站点汇总账** |
| 旁路 | 迟到匣 | 悬账缺边 | **坏点匣（未过门槛）** |

皮：环境监测传感站（大气/水质探头）。去皮：**标定质控门槛 + 入栏 + 汇总物化 + 坏点旁路 + 栏贯验**。  
禁止做成运维工单、告警大屏、传感器 CRUD。禁止抄潮切窗号/对拍左右轨命名。

## 实装

`报文键幂等`：同一报文编号重复装载只保留首条命运。栏规键 `幂等策略` 择定形态：
- `切流账册`（默认）：账册登记已吃进编号，同号回刷整票拒绝，账册能回看拒因，现行行数不涨。
- `双写归档`：同号回刷旧报文落只读归档，现行装载只读新编号集合，现行与归档分开可读。

查重判定与流水回执同事务（装载整批 BEGIN IMMEDIATE）；账册主键即互斥，两路同号并发只一路入栏。
只读接口：`GET /api/同号裁决`（策略/汇总/裁决流水/归档，现行条数与归档条数分开），`GET /api/同号裁决?编号=X`（单号回看）。
对账：`统计.装载批次对账(批次编号)` 回执与库实逐格核对，驳回不得计为入栏成功（伪绿）。
测：`tests/test_dupmsg_a.py`（切流/双写现行不涨）· `tests/test_dupmsg_b.py`（批次对账诚实）· `tests/test_dupmsg_c.py`（并发不双行）· `scripts/并发双请求.py`。
